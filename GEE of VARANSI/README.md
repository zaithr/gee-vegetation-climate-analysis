## Overview
This project analyzes vegetation dynamics and climate interactions in Varanasi using multi-temporal Landsat and CHIRPS datasets (1988–2024).

## Objectives
- Analyze seasonal NDVI and SAVI trends
- Study land surface temperature variation
- Assess rainfall–vegetation relationships

## Methodology
- Landsat 5, 8, 9 Surface Reflectance
- NDVI & SAVI (threshold = 0.23)
- Seasonal compositing
- CHIRPS rainfall aggregation
- Mann-Kendall trend analysis

## Key Findings
- Increasing vegetation variability post-2014
- Strong monsoon influence on NDVI
- Rising LST trends in urban regions
